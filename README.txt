LOAN SAVER CALCULATOR
=====================

Files:
- index.html  : complete self-contained website (HTML + CSS + JavaScript)

Hosting:
1. Upload index.html to your web server's public_html/www folder.
2. Open your domain.
3. No PHP, database, Node.js or build process is required.

Notes:
- Calculations run in the visitor's browser.
- Currency is RM / Malaysian Ringgit.
- The amortization schedule is generated dynamically and can be exported to CSV.
- The MTRP section models regular savings as an investment account compounded monthly, then compares the account value with the outstanding mortgage balance.
- The target-age section calculates the mortgage balance at the selected target age and the investment/lump-sum amount needed to reach it.
- Change DEFAULT_DOB in the JavaScript if you want the age calculation to use a different client DOB.
